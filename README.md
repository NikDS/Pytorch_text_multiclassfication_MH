# 🧠 Sentiment Analysis for Mental Health

A fun weekend project using PyTorch and a public Kaggle dataset to classify mental health-related statements based on their sentiment or status.

> Dataset source: [Sentiment Analysis for Mental Health – Kaggle](https://www.kaggle.com/datasets/suchintikasarkar/sentiment-analysis-for-mental-health)

---

## 📌 Features

- Preprocesses statements using TF-IDF vectorization
- Trains a simple feedforward neural network using PyTorch
- Visualizes confusion matrix and classification report
- Makes real-time predictions on custom input text
